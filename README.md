## chessbotillegal

A browser chess sandbox for playing against Stockfish or Bytecat. Move either color to any square, capture allies, spawn extra pieces, remove kings, and swap sides with Reality flip. The sandbox engine takes over on unconventional boards. The piece library includes two originals, Illuminator and Phantom, plus a forge for creating pieces with custom names, images and powers.

### Run locally

From the repository root, run `python3 -m http.server 8000` and open `http://localhost:8000/`. The site is static and includes its engines, fonts, and artwork. Games and custom pieces are saved in the current browser.

### GitHub Pages

The root of `main` is ready for branch-based GitHub Pages hosting. Select `main` and `/(root)` in Settings → Pages to publish a GitHub Pages copy.
